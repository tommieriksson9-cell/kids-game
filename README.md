# Blocky Quest

A child-friendly, offline-first 3D block-world adventure prototype for Android, designed for ages 6–12.

## Project status

This repository is being set up. The first milestone is a Godot 4 prototype with simple exploration, age-appropriate difficulty options, local progress saving, and language selection. It is not yet a finished game or a tested Android APK.

## Child-safety defaults

- Offline-first; no public chat or location tracking.
- Save progress locally on the device.
- Keep settings simple and age-appropriate.
- Add no advertising or analytics by default.

## Planned build

The project will use Godot 4 and a GitHub Actions workflow to export an Android APK once the game project and Android export configuration are in place.
