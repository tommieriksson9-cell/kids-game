# Blocky Quest

A child-friendly, offline-first block-world adventure prototype for Android, designed for ages 6–12.

## Adventure length and replayability

The prototype now has **12 themed worlds**, with 8 collectible stars in each world. Players can explore at their own pace, collect stars, unlock the next world by completing the current one, and keep building their total star count. After the final world, the star hunt loops back to the first world so play can continue.

World themes include Sunny Meadow, Candy Canyon, Frosty Peaks, Jungle Ruins, Moon Garden, Ocean Bay, Desert Dunes, Cloud Kingdom, Crystal Caves, Autumn Woods, Lava Lights, and Rainbow Summit.

## Controls

- Desktop: WASD or arrow keys to move; Space to collect a nearby star.
- Touch: tap to move toward a point and collect a nearby star.
- Progress saves locally on the device.

## Child-safety defaults

- Offline-first; no public chat or location tracking.
- Local progress saving; no account required by this prototype.
- No advertising or analytics included by default.

## Project status

This is an early Godot 4 prototype, not a finished game. The current game uses simple 2D block-style graphics as a playable foundation. Future milestones can add a full 3D world, more varied quests and puzzles, accessibility options, language selection, and a parent-facing progress report.

## Android build

The repository includes a GitHub Actions validation workflow. A release APK is not yet available; Android export settings and a successful build need to be verified before an installable APK can be shared.
